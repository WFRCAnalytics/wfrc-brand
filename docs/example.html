NoteNote

PTI is unitless. A value of 1.5 means a 20-minute free-flow trip needs 30 minutes of budget.

TipTip

Filter to non-holiday weekdays before computing percentiles.

ImportantImportant

Segments with fewer than 200 valid observations are excluded rather than imputed.

WarningWarning

Do not compare PTI across periods with different free-flow baselines.

CautionCaution (collapsible)

Rebuilding the network invalidates cached segment IDs. Re-run make segments first.

Listings

Grid listings get the card surface (--wfrc-card-bg, a light blue that differs from the page and from .wfrc-band-alt), a banner and a hover lift. Banners are assets/cards/{navy,mid,teal,bright,brick}.svg with image-height: 84px; the decorative-image script gives them an empty alt. A site must list the banners under project.resources (see the README).

# People within 400 m of either end of a gap
gaps <- read_sf("data/gaps.gpkg") |>
  mutate(
    reach = st_reach(geometry, pop, 400),
    score = rescale(reach) * 0.6 + rescale(jobs) * 0.4
  ) |>
  arrange(desc(score))
py/reliability.py
import pandas as pd

df = speeds.query("~is_holiday and period == 'am_peak'")
pti = (df.groupby("segment_id")
         .agg(tt_95=("tt", lambda s: s.quantile(0.95)),
              tt_ff=("tt_ff", "first"))
         .assign(pti=lambda d: d.tt_95 / d.tt_ff))

library(dplyr)
pti <- speeds |> group_by(segment_id) |> summarise(pti = quantile(tt, 0.95) / first(tt_ff))
pti = df.groupby("segment_id").tt.quantile(0.95) / df.groupby("segment_id").tt_ff.first()
SELECT segment_id, PERCENTILE_CONT(0.95) WITHIN GROUP (ORDER BY tt) / MIN(tt_ff) AS pti
FROM speeds GROUP BY segment_id;
