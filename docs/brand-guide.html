Brand guide

Colors, type, logos and chart colors, read from the theme

Everything on this page comes from brand.yml. The swatches are drawn from the --brand-* CSS variables Quarto generates from the palette, so they cannot drift from the real values. Switch the page to dark mode with the toggle in the navbar to see the dark roles.

Color roles

These are the semantic colors in brand.yml (color.primary, color.background and the rest). Each has a light and a dark value, and Bootstrap, Shiny and Typst all read them.

Palette

Every named color in color.palette, grouped by what it is for. Names are the Sass variable ($brand-wfrc-navy) and the CSS variable (var(--brand-wfrc-navy)). The theme SCSS maps roles onto these names and never writes a hex code of its own.

NoteContrast

Bright blue (wfrc-bright-blue) is 3.5:1 on white: use it for rules, focus rings and large fills only. Buttons and interactive fills use wfrc-action (5.0:1). Brick (wfrc-brick) is 4.5:1, so a brick fill that carries small white text uses wfrc-brick-deep (5.5:1).

Type

Headings: Inter 700

Planning the Wasatch Front

Body: Poppins 400 at 16px, line height 1.6

Population grew 2.1% last year, and jobs grew faster than housing across the four counties.

Code: Fira Code 400

pti = tt_95 / tt_ff

Fonts load from Google Fonts by default. To bundle them instead, point project.brand at _extensions/wfrc-brand/brand-offline.yml.

Logos

brand.yml ships three logo shapes in color and white. Quarto picks the color version on light pages and the white one on dark pages (logo.small, medium and large have light and dark values), and every logo carries alt text.

Do not recolor, stretch or add effects to the logo, and keep clear space around it equal to the height of the “W”.

Chart colors

Five categorical colors in a fixed order. They pass lightness, chroma and color-vision checks. Never cycle past five: facet, or group the rest as “Other”. Gold is below 3:1 on white, so label series directly instead of relying on a legend.

The helpers read these from brand.yml: wfrc-charts.R (ggplot2), wfrc_charts.py (matplotlib, plotly) and wfrc-charts.js (Observable Plot). See the components example for each in use.
